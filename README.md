# AA_Team_6

## How to run
### Create an environment from the environment.yml file

Open a terminal in the root of the project and run this command

```
conda env create -f environment.yml
```

### Overal Struture

There is one notebook for each of the four tasks. The session data changed by the preparation notebook will be save in the data_processed folder


### Exectue the notebooks

Select the enviorment `aa_project_env` for notebooks to run. The notebooks can be executed invididually from each other, but to create the necessary files for notebook 02,03 and 04 Notebook: 01_preperation.ipynb need to be executed to create these files.
